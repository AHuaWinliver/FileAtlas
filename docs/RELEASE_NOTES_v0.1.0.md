# FileAtlas 0.1.0

首个可运行版本，面向 Windows 11 x64。

支持多级分类与独立保存位置、本地 Claude Code 分类和标签、源目录实时监控、待审核与自动归档、文件树生成和 Markdown 导出，以及带哈希校验的归档记录和撤销。

界面采用浅色半透明 Acrylic 背景与圆角面板。

## 使用方法

下载 `FileAtlas-0.1.0-win64.zip`，解压后运行 `FileAtlas.exe`。配置分类与源文件夹后扫描，确认效果后开启自动监控。实际 AI 分类需要自行安装并配置 Claude Code。

## 验证与限制

已验证 12 项核心文件处理测试、目录监控、六个界面页面和真实本地模型分类。

当前没有 OCR；图片、扫描 PDF 等按名称和元数据分类。应用为早期版本，尚未完成长期耐久和断电故障注入测试。默认采用复制模式并保留人工审核。
