# CAE 工程模板

在“分类与目录”选择“创建 CAE 工作空间”，指定根目录并确认预览。模板添加 `00_待整理` 为源目录，建立项目库、公共资源库、知识与方法、已结项归档。既有文件保留原位，不覆盖文件或更改已有模型配置；不会自动启动监控。

点击“新建工程项目”，填写唯一编号（如 `P2026-001`）、客户或部门、项目名称与关键词。软件建立：

```text
项目编号_客户_项目名称/
├─ 00_项目管理/需求与任务书、计划与会议、技术沟通
├─ 01_原始输入/原始CAD、材料与试验数据、载荷与边界条件
├─ 02_模型准备/几何清理与简化、网格与连接、模型检查
├─ 03_仿真任务/C001_基准工况/输入、求解、日志
├─ 04_结果分析/曲线与数据、云图与动画、对比与验证
├─ 05_报告与交付/报告草稿、审核记录、正式交付
└─ 90_历史版本
```

每个节点可通过“编辑分类”指定独立保存地址。修改地址影响后续整理，不搬移已有文件；修改项目库地址后，新项目使用新的项目库地址。

## 自动整理

将独立资料放入收件箱，例如 `P2026-001_齿轮箱_分析报告_V03.docx`。配置 Claude Code 后扫描并审核，确认效果再启用自动执行。

项目编号不明、同时出现多个编号、编号与推荐分类不符，或含项目编号却推荐公共分类时，均要求人工审核，不能通过降低置信度阈值绕过。编号检查使用文件名及路径，正文编号不会解除此要求。归档标签加入所选项目编号。

无项目编号的通用资料仍按公共分类与原有置信度规则整理。

## 工况保护

仿真任务、基准工况、历史版本与已结项归档是受保护容器，不接收 AI 分配的零散资料。

CAE 模式下，以下扩展名保留原位，不调用 AI、不执行归档：

`.cae .odb .sim .rst .res .op2 .fem .inp .bdf .bin .adm .acf .cmd .cas .dat .msh .cdb .wbpj .mechdb .db`

收件箱子文件夹含有上述文件时，其配套资料也受保护。带 `.fileatlas-case.json` 标记的目录同样受保护。文件资料库显示保护状态与原因。

这是保守的扩展名保护，不是完整的求解器依赖解析。未知格式或仅含脚本的任务可能无法识别，活动求解目录应放在监控源之外。当前版本不自动移动、压缩或修改完整工况目录，请按完整目录归档。
