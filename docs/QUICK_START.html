WINDOWS 11 · CAE 工程文件管理

FileAtlas 0.2.0 使用说明

创建工程目录，给独立资料自动打标签与归类，同时保留求解任务的依赖关系。

1. 安装与启动

  • 安装版：运行 FileAtlas-0.2.0-Setup.exe，按向导安装到当前用户目录。
  • 便携版：解压 FileAtlas-0.2.0-win64.zip，双击 FileAtlas.exe，保留旁边的 _internal 文件夹。
  • AI 分类需自行安装、登录并配置 Windows 原生 Claude Code。没有模型配置时仍可创建目录和项目。

2. 创建 CAE 工作空间

  1. 打开“分类与目录”→“创建 CAE 工作空间”。
  2. 选择根目录，检查预览，再确认创建。
  3. 软件建立待整理、项目库、公共资源库、知识与方法、已结项归档。
  4. 点击“新建工程项目”，填写项目编号、客户或部门、项目名称和分类关键词。
项目编号_客户_项目名称/
├─ 00_项目管理
├─ 01_原始输入
├─ 02_模型准备
├─ 03_仿真任务/C001_基准工况/输入、求解、日志
├─ 04_结果分析
├─ 05_报告与交付
└─ 90_历史版本

3. 扫描与自动归档

  1. 在“自动化设置”确认整理源、Claude Code 路径与模型，保存。
  2. 将独立资料放入 00_待整理。推荐文件名：P2026-001_齿轮箱_分析报告_V03.docx。
  3. 点击“扫描源文件夹”，先在“待审核”确认分类。
  4. 确认效果后，设置复制或移动方式，开启“自动执行”，点击“启动自动监控”。
项目编号不明、多项目编号冲突或分类不匹配时，必须人工审核。原生求解文件及识别到的工况配套资料保留原位。保护规则不能代替完整求解器依赖解析，活动求解目录请放在监控源之外。

4. 搜索、目录与撤销

  • “文件资料库”：按文件名、路径、分类和标签搜索，查看保护原因。
  • “分类与目录”：编辑各节点保存地址、导出 Markdown 文件树；改地址不搬移现有文件。
  • “整理记录”：选择成功操作并撤销；文件已被修改或原路径被占用时会阻止撤销。

5. 退出、更新与数据

关闭窗口默认继续在托盘运行。右键托盘图标退出后，再安装更新。重新启动程序后需手动启动监控。

配置、标签和历史保存在 %LOCALAPPDATA%\FileAtlas，卸载保留此目录。备份时先退出程序，再复制整个目录。

使用云模型时，文件名、路径及启用的内容摘录会发送给所配置的服务；可关闭内容提取。

6. 源码与其他文档

解压源码 ZIP，使用 Python 3.12 创建虚拟环境，安装 requirements-dev.txt 后运行 app.py。工程规则见 CAE_WORKFLOW.md，通用说明见 USER_GUIDE.md。源码同时附有中英文 README。
