# FileAtlas 0.2.1

本版修复保存设置后开启监控时扫描线程退出的问题。设置页新增 **保存并启动自动整理**，保存后立即扫描已有文件。目录事件监控启动失败时，程序仍会定时扫描。

分类依据可单独填写一行 `扩展名规则：.pdf .docx`。只有一个分类匹配时，程序使用该分类并添加扩展名标签。其余情况由模型判断。项目编号审核和工况保护仍适用。

修复部分 Windows 数据目录中临时文件替换失败导致的 Markdown 导出错误。

- `FileAtlas-0.2.1-Setup.exe` 为 Windows 安装包。
- `FileAtlas-0.2.1-win64.zip` 为便携版。
- `FileAtlas-0.2.1-source.zip` 为完整源码。
- `FileAtlas-0.2.1-complete.zip` 包含安装包、便携版、源码和使用说明。
- `SHA256SUMS.txt` 用于校验下载文件。

已验证 24 项单元测试、监控集成流程、窗口和 EXE 启动，以及本机 22 个文件的复制归档。安装包已编译，真实安装与卸载未纳入本次验证。
