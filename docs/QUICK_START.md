# FileAtlas 0.2.0 使用说明

## 安装与启动

- 安装版：运行 `FileAtlas-0.2.0-Setup.exe`，按向导安装到当前用户目录。
- 免安装版：解压 `FileAtlas-0.2.0-win64.zip`，运行 `FileAtlas.exe`，保留 `_internal` 文件夹。
- AI 分类需要自行安装、登录并配置 Windows 原生 Claude Code；没有模型时仍能创建分类与工程目录。

## CAE 人员推荐流程

1. “分类与目录”→“创建 CAE 工作空间”，选定根目录，确认预览后创建。
2. “新建工程项目”，填写项目编号、客户或部门、项目名称和关键词，生成阶段目录与基准工况。
3. “自动化设置”确认整理源、Claude Code 路径与模型，然后保存。
4. 将带项目编号的独立文档放入 `00_待整理`，例如 `P2026-001_分析报告_V01.docx`。
5. 点击扫描，在待审核检查分类，再决定是否开启自动执行与监控。
6. 文件资料库支持标签检索和保护原因查看；分类与目录支持导出 Markdown；整理记录支持撤销成功操作。

初始默认复制并保留人工审核。项目编号不明时转人工审核；求解文件及识别到的工况配套资料保留原位。

## 配置与退出

配置、标签及日志保存在 `%LOCALAPPDATA%\FileAtlas`。卸载保留此数据目录。备份时请先退出程序，再复制整个目录。

关闭窗口默认继续在托盘运行；右键托盘图标可退出。更新前退出旧版，重启后手动启动监控。

云模型会接收文件名、路径及启用的内容摘录；可在设置中关闭内容提取。具体处理方式取决于 Claude Code 的服务配置。

详见 [CAE 工程流程](CAE_WORKFLOW.md)、[完整使用指南](USER_GUIDE.md)，以及源码根目录的英文 `README.en.md`。
